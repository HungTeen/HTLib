# Your First Raid

Add the following JSON file named `first_raid` under the `raid` path to create your first raid. This raid has two waves and uses the mod's built-in presets.

```json
{
  "type": "htlib:common",
  "setting": {
    "bar_setting": {
      "raid_bar_color": "blue"
    },
    "border_setting": {},
    "sound_setting": {
      "loss_sound": "htlib:loss",
      "raid_start_sound": "htlib:prepare",
      "victory_sound": "htlib:victory",
      "wave_start_sound": "htlib:huge_wave"
    },
    "victory_results": [
      "htlib:test"
    ]
  },
  "waves": [
    "htlib:test_1",
    "htlib:test_2"
  ]
}
```

To verify the raid was added successfully, use the following command after joining a world (replace `mod_id` with your data pack namespace):

```plain
/htlib raid create htlib:default_raid mod_id:first_raid ~ ~ ~
```
