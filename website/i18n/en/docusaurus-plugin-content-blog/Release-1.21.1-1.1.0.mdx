Multi-platform support! Starting from this version, custom raid content has been split into a standalone mod: **Custom Raid**.

{/* truncate */}

## New Features
* Multi-platform support — now available on Forge, NeoForge, and Fabric.
## Bug Fixes
* Fixed an issue where virtual entities would remain after a player disconnected due to network issues and rejoined a local game.
## Other Changes
* Performance optimization — improved concurrency in the registration system.
* Network optimization — improved efficiency of data pack C/S synchronization.
