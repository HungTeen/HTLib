# 清除袭击者

移除所有存活的袭击者，通常用于袭击失败时清理战场。

## 字段说明

| 字段 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `type` | 字符串 | — | 固定为 `htlib:clear_raider` |
| `clear_tick` | 整数 | `0` | 在结果触发后多少 tick 执行清除 |

### 示例

```json
{
  "type": "htlib:clear_raider",
  "clear_tick": 0
}
```
