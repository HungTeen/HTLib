# 波组件

波组件定义了一次袭击中的单个波次，指定了这一波中会生成哪些怪物、持续多长时间、以及是否可以跳过。

波组件的 JSON 文件存放在 `data/<mod_id>/htlib/wave/` 路径下。

```plain
.
├── data
│   └── mod_id
│       └── htlib
│           ├── raid              ← 袭击定义
│           ├── wave              ← 波次定义
│           ├── spawn             ← 怪物生成
│           ├── position          ← 生成位置
│           ├── result            ← 结果/奖励
│           └── raid_item         ← 袭击召唤物品
```

## 类型汇总

| 类型 | 描述 |
|------|------|
| `htlib:common` | 一般波，由多组怪物生成组成 |
